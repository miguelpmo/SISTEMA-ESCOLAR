# SISTEMA ESCOLAR

VERSÃO ORGANIZADA PARA DEPLOY NA VERCEL, MANTENDO O CSS E O LAYOUT EXISTENTES.

## COMEÇAR

1. LEIA `GUIA_COMPLETO.md`.
2. CONFIGURE AS VARIÁVEIS DE AMBIENTE DA VERCEL.
3. CONFIRA O BANCO SUPABASE COM `SUPABASE/DIAGNOSTICO.SQL`.
4. REVISE AS POLÍTICAS DE `SUPABASE/POLITICAS_RLS.SQL` ANTES DE EXECUTAR.
5. PUBLIQUE PELO GITHUB/VERCEL E SIGA O CHECKLIST DO GUIA.

## ESTRUTURA

- `index.html`: telas.
- `css/style.css`: layout original, preservado.
- `js/`: lógica do navegador.
- `api/`: funções seguras do servidor.
- `supabase/`: diagnóstico e modelo de políticas.

## IMPORTANTE

A CHAVE `SUPABASE_SERVICE_ROLE_KEY` DEVE FICAR SOMENTE NAS VARIÁVEIS DA VERCEL. NÃO COLOQUE ESSA CHAVE NO CÓDIGO-FONTE.
